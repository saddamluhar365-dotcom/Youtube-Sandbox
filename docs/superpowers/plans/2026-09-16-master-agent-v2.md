# YouTube Sandbox Master Agent v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the public-data-only six-channel intelligence system and locked 90-second Shorts production pipeline described by the v2 architecture.

**Architecture:** Keep the existing FastAPI/SQLite/FFmpeg foundation, add focused modules for provider pools, persistent intelligence, channel/video analysis, Level 3 blueprinting, Level 4 sequential asset execution, and Level 5 editing/delivery. Provider identity and model identity are locked per project while credential slots rotate inside the locked provider.

**Tech Stack:** Python 3.12+, FastAPI, Pydantic, SQLite, httpx, FFmpeg/ffprobe, pytest, Tavily, Gemini, Hugging Face, fal.ai.

**Spec:** `docs/superpowers/specs/2026-09-16-master-agent-v2-design.md`

## Global Constraints

- Public YouTube data only; no OAuth/private Analytics/publishing.
- One owned channel handle plus exactly five reference channels.
- Actual public video content is analyzed, not metadata alone.
- SQLite is persistent intelligence memory; secrets never enter SQLite.
- Tavily is the web-research provider; Gemini is the LLM provider; Hugging Face is the character-reference provider.
- Video generation uses one provider and one locked model per Short; credential slots may rotate inside that provider.
- Character reference pack is generated by Hugging Face and reused for all nine scenes.
- Exactly nine sequential 10-second clips per Short.
- Each clip is generated, downloaded, verified and registered before the next clip starts.
- Level 5 edits only after all nine clips pass QA.
- Final master is 1080x1920 and exported by sanitized recipe name outside the sandbox.
- Sandbox cleanup occurs only after final output verification; permanent intelligence remains.
- No fabricated metrics; use `INSUFFICIENT_DATA` when public evidence cannot establish a signal.
- CI must be green before completion is claimed.
